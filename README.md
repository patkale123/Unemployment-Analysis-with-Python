# 📊 Unemployment Analysis with Python

## 📌 Project Overview

Unemployment Analysis with Python is a data analysis project that explores unemployment trends in India. The project analyses unemployment rates across different regions and compares urban and rural unemployment patterns.

It also investigates changes in unemployment during the COVID-19 pandemic using data visualisation and an interactive Streamlit dashboard.

## 🎯 Project Objectives

- Analyse unemployment rates across different Indian regions.
- Compare unemployment rates in urban and rural areas.
- Study unemployment trends over time.
- Analyse the impact of the COVID-19 period.
- Identify monthly and yearly unemployment patterns.
- Present meaningful insights through visualisations.

## 📂 Dataset

**Dataset Name:** Unemployment in India

**Source:** Kaggle

Dataset Link: https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india

### Important Features

| Feature | Description |
|---|---|
| Region | Indian state or region |
| Date | Date of observation |
| Frequency | Reporting frequency |
| Estimated Unemployment Rate (%) | Unemployment percentage |
| Estimated Employed | Estimated employed population |
| Estimated Labour Participation Rate (%) | Labour participation percentage |
| Area | Urban or Rural |
